## Beyond Root

The challenge was complete, but I needed a short reminder on how to get an SSH-connection running from this point. I know that we're root already, but say we were a low-privilege user and I simply wanted a stable shell from which to further escalate privileges. That's what this is for.

First, copy my attacker SSH public key, i.e. 

```console
kali@kali:~/Projects/THM/bolt$ cat /home/kali/.ssh/id_ed25519.pub 
ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIBkpqL+7FTAp2Ce6WR/E3OWRu0eAnGz3twx8ucDYiCO4 kali
```

Next, append (the `>>` is important in order not to overwrite existing keys) this key to the `authorized_keys` file on the victim machine:

```console
echo "ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIBkpqL+7FTAp2Ce6WR/E3OWRu0eAnGz3twx8ucDYiCO4 kali" >> /root/.ssh/authorized_keys
```

Lastly, SSH onto the box while specifying your private key:

```console
kali@kali:~/Projects/THM/bolt$ ssh -i /home/kali/.ssh/id_ed25519 root@bolt.thm
```

A few notes:

1. In this (contrived) example we have the user `root` to begin with. Otherwise, one must likely look for `/home/USER/.ssh/authorized_keys` instead.
2. I had saved `bolt.thm` in my `/etc/hosts` file. Normally, this is just the victim IP-address.

Now we have a stable SSH-connection!
